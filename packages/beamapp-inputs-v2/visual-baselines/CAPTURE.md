# Visual baseline procedure

The manifest is the contract for visual comparison. PNGs are not generated by
unit tests: they must be captured from the same browser surface and viewport as
the current Inputs page.

For every state in `manifest.json`:

1. Start the current Runtime and isolated V2 on different ports.
2. Capture the current page first at the declared viewport.
3. Reproduce the same state in V2 without importing Runtime code or state.
4. Capture V2 at the identical viewport as `<state>--v2.png` beside the current
   reference.
5. Run the agreed image diff and record its result.
6. Record and approve any intentional difference before changing the manifest
   status from `reference_capture_pending`.

Required states include default, expanded/collapsed sections, count and
spacing reinforcement modes, one- and two-row reinforcement, validation,
updating/error, and desktop/narrow viewports. A state passes only when both its
image diff and browser interaction test pass.
